# gimbal-trigger-cam

Курок стабилизатора **Feiyu Scorp-C** (модель F2C) работает как спуск стандартной камеры Android.

## Как это работает

Гимбал не сообщает по Bluetooth об одиночном нажатии курка, но сообщает о **смене режима**: пока курок зажат, он в режиме Lock (байт 9 кадра телеметрии `A5 5A 00 FF 1E 00 …` меняется `01 → 03`). Приложение держит связь с гимбалом в фоне, ловит это и через [Shizuku](https://shizuku.rikka.app/) нажимает «громкость +» — в стандартной камере это спуск: фото в режиме фото, старт/стоп записи в режиме видео.

Режимы:
- **Сразу при зажатии** (по умолчанию) — быстрее всего.
- **При отпускании** — короткое и длинное удержание можно назначить на разные действия.

## Установка

**[Скачать gimbal-trigger-cam.apk](../../releases/download/latest/gimbal-trigger-cam.apk)** — собирается автоматически после каждого изменения, новые версии ставятся поверх старой.

### Shizuku

1. Установите Shizuku из [Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) или [GitHub](https://github.com/RikkaApps/Shizuku/releases).
2. В настройках телефона включите «Для разработчиков» → «Отладка по Wi-Fi» (на Xiaomi также «Отладка по USB»).
3. В Shizuku: «Запустить через беспроводную отладку» → «Сопряжение» и введите код из уведомления.
4. После перезагрузки телефона Shizuku нужно запустить снова (шаг 3 без сопряжения).

### Xiaomi / HyperOS

Чтобы система не убивала фоновую работу: «Настройки → Приложения → Курок гимбала» → **Контроль активности: Нет ограничений** и включить **Автозапуск**.

## Использование

1. Закройте официальное приложение Feiyu (гимбал держит одно подключение).
2. В приложении: Shizuku → «Дать разрешение», «Найти гимбал», «Запустить».
3. Откройте стандартную камеру и нажмите кнопку ⇄ (или зажмите курок).

«Разведчик» в разделе «Диагностика» показывает сырые данные гимбала — для исследования протокола.

## Протокол

Подробно: [docs/PROTOCOL.md](docs/PROTOCOL.md). Кратко:

- BLE-сервис `FFFF`: уведомления `FF02`, запись `FF01` (без ответа).
- Кадр: `A5 5A` · источник · получатель · команда (2 байта LE) · msgId · длина N (2 байта LE) · данные · CRC-16/XModem (LE).
- cmd 30 — состояние гимбала ~20 Гц: режим следования (при зажатом курке 1 → 3), углы, батарея.
- **Кнопка ⇄** при каждом нажатии присылает cmd 129 — это и есть одиночное нажатие для спуска. Удержание курка видно по смене режима. REC, кнопка фото и одиночный щелчок курка по BLE не передаются.

## Сборка вручную

JDK 17, Android SDK, Gradle 8.7: `gradle assembleDebug`.
