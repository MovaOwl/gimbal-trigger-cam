# gimbal-trigger-cam

Цель проекта: курок стабилизатора **Feiyu Scorp-C** (модель F2C) работает как спуск стандартной камеры Android — фото или старт/стоп видео.

План:

1. **Разведчик (текущая версия 0.3-scout)** — подключается к гимбалу по Bluetooth LE и записывает всё, что он присылает при нажатии кнопок. Так мы узнаём протокол.
2. **Рабочая версия** — фоновый сервис ловит нажатие курка и через [Shizuku](https://shizuku.rikka.app/) нажимает «громкость», на что реагирует любая стандартная камера.

## Установка

Свежий APK собирается автоматически после каждого изменения:

**[Скачать gimbal-trigger-cam.apk](../../releases/download/latest/gimbal-trigger-cam.apk)**

При первой установке Android попросит разрешить установку из этого источника (браузера/файлового менеджера). Новые версии ставятся поверх старой.

## Как пользоваться разведчиком

1. **Закройте официальное приложение Feiyu** (смахните из недавних) — гимбал держит только одно подключение.
2. Включите гимбал, откройте Gimbal Scout, нажмите **«Сканировать»** и разрешите доступ к Bluetooth.
3. Выберите гимбал в списке (подходящие имена отмечены ★).
4. Дождитесь строки «Готово: подписан на N каналов».
5. Ничего не трогая, подождите 5 секунд — это фон. Если какой-то канал непрерывно сыплет данными (например, углы наклона), его можно скрыть кнопкой **«Фильтр»**. Телеметрия углов скрыта по умолчанию.
6. Для каждого действия: **«Метка»** → выберите, что сейчас нажмёте → нажмите это на гимбале 3–4 раза с паузой в секунду.
   Обязательно: курок одиночный, двойной, удержание; кнопка фото на ручке; FPV.
7. **«Поделиться»** или **«Копировать»** — отправьте журнал.

Поле «Запись» понадобится позже для проверки команд; пока его можно не трогать.

## Сборка вручную

Нужны JDK 17 и Android SDK: `gradle assembleDebug` (Gradle 8.7).
