# Протокол Feiyu «AK» по Bluetooth LE (Scorp-C / F2C)

Описание составлено по наблюдению трафика гимбала и изучению официального приложения Feiyu SCORP 1.5.12 ради совместимости. Код приложения в репозиторий не копируется.

Статус: ✅ проверено на устройстве · 🔎 найдено в приложении, ещё не проверено.

## Транспорт ✅

| | UUID |
|---|---|
| Сервис | `0000ffff-0000-1000-8000-00805f9b34fb` |
| Уведомления (гимбал → телефон) | `0000ff02-…` |
| Запись без ответа (телефон → гимбал) | `0000ff01-…` |

Кадр может прийти разрезанным на несколько уведомлений — их нужно склеивать.

## Формат кадра ✅

```
A5 5A | src | dst | cmd(2, LE) | msgId | len(2, LE) | data[len] | crc(2, LE)
```

- `cmd = (тип << 13) | id`. Типы: 0 — push (уведомление), 1 — set, 2 — get, 3 — ответ на set, 4 — ответ на get.
- `crc` — CRC-16/XModem (полином 0x1021, начальное 0) по байтам от `src` до конца `data`.
- Полная длина кадра = `len + 11`.

Адреса: 0, 1, 2 — узлы гимбала (A, B, C), 3 — приложение, 4 — модуль кнопок, 6 — Bluetooth-модуль, 9 — USB-хаб, `FF` — всем.

## Что присылает гимбал

| cmd | от → кому | Частота | Смысл |
|---|---|---|---|
| 30 ✅ | 0 → FF | ~20 Гц | Состояние гимбала (ниже) |
| 73 ✅ | 9 → 3 | ~5 Гц | Подключение USB-камеры (у нас нули) |
| 80 🔎 | → 3 | по нажатию | Событие кнопки (у Scorp-C нет) |
| 114 🔎 | → 3 | | Гимбал спрашивает статус приложения (тип set), нужно ответить |

### cmd 30 — состояние гимбала ✅

| Байт данных | Смысл |
|---|---|
| 0 | биты 0–2 — режим следования, бит 3/4 — доступны селфи/вертикальная съёмка, бит 6 — ориентация установки, бит 7 — идёт таймлапс |
| 1–2 | курс (yaw), int16 LE, сотые градуса |
| 3–4 | крен (roll), int16 LE, сотые градуса |
| 5–6 | тангаж (pitch), int16 LE, сотые градуса |
| 7 | уровень батареи |
| 8 | бит 2 — ожидание, бит 3 — селфи |
| 9 | тип текущей задачи |
| 10–12 | усилие моторов pitch / roll / yaw |

Режим (биты 0–2): 0 Lock, 1 следование по курсу, 2 курс+тангаж, 3 полное следование. При зажатом курке Scorp-C значение меняется `1 → 3` — на этом построена версия 1.0.

### cmd 80 — событие кнопки 🔎

`data[0]` — функция, `data[1..2]` — параметры. Функции: 0 фото, 1 видео, 2 смена режима камеры, 3 смена камеры, 5 зум/параметр, 6 меню, 7 джойстик (data[1..2] — отклонение), 9 серийная съёмка, 10 умное слежение, 11 фиксация по центру, 16 зум, 17 слежение за лицом, 19/20 панорама 180/360.

**Scorp-C их не присылает ✅.** В официальном приложении у модели Scorp-C (config `scorp_c.json`) нет ни статуса приложения, ни событий кнопок: эти функции есть у смартфонных гимбалов Feiyu. Проверено: «статус приложения» гимбал принимает молча, красная кнопка REC и кнопка фото по BLE ничего не сообщают — они работают только с камерой по кабелю. Из кнопок по BLE виден только курок (через режим в cmd 30).

## Что отправляет приложение

| cmd | Тип → кому | Данные | Смысл |
|---|---|---|---|
| 114 🔎 | push → 4 | `[на экране 0/1, флаги, 4, фронт. камера]` раз в 1 с | Статус приложения |
| 153 🔎 | push → цель | — | Пульс |
| 14 🔎 | push → 0 | `[крен вкл 0/1, курс int16, тангаж int16]` | Джойстик (скорость) |
| 113 🔎 | push → 0 | `[курс, крен, тангаж]` int16 | Управление движением |
| 93 🔎 | set → 2 | `[ось, угол int16]` | Повернуть на заданный угол |
| 115 🔎 | set → 0 | `[курс, крен, тангаж]` int16 (+скорость) | Повернуть относительно |
| 50 🔎 | set → 2 | `[режим]` | Режим следования |
| 51 🔎 | set → 2 | `[0 сон, 1 разворот, 2 в исходное, 3 проснуться]` | Режим использования |
| 83 🔎 | set → 2 | `[0/1]` | Селфи |
| 32 🔎 | get/set → 2 | `[id параметра, значение int16 BE]` | Пользовательские параметры |

Пример готового кадра «приложение на экране»: `A5 5A 03 04 72 00 00 04 00 01 00 04 00 A2 04`.

### Пользовательские параметры (cmd 32) 🔎

Скорость/инверсия джойстика (10–13), мёртвая зона и скорость следования по осям (14–19), **функция курка (36)**, функции кнопки режима при 1/2/3/4 нажатиях (40, 37, 38, 39), функция кнопки M (45), второй курок (42–44), автоцентровка (46), режим при включении (41).

Функция курка (36): 0 — тангаж, 1 — курс, 2 — FPV, 3 — быстрое следование, 4 — вспышка, 5 — Lock. То есть курок прошивка умеет назначать только на «режим, пока зажат» — короткое нажатие отдельно не передаётся.

## Не трогать без необходимости ⚠️

Сила моторов (62, 130), калибровка гироскопа (40), сброс настроек (49), перезагрузка (52), всё, что связано с прошивкой (16–19, 38, 58, 65–67, 132, 162), сохранение системных параметров (31). Ошибка может нарушить работу гимбала.
